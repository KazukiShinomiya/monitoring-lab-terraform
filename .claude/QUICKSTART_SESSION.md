# 🔄 セッション継続機能 - クイックスタート

このプロジェクトでは、Claude Codeとのセッションをまたいで作業を継続できる仕組みを実装しています。

---

## 📌 セッション継続の仕組み

### 自動状態管理ファイル
**ファイル**: `.claude/SESSION_STATE.md`

このファイルには以下の情報が記録されます:
- ✅ 完了した作業の履歴
- 🚧 未完了のタスクと優先度
- 🐛 既知の問題と回避策
- 📁 重要なファイルパス
- 🔧 よく使うコマンド

---

## 🚀 使い方

### 1️⃣ 新しいセッションを開始する

Claude Codeを起動したら、最初に以下のコマンドを実行してください:

```
/init
```

**実行内容**:
- 前回セッションの作業内容を表示
- 未完了のタスクを確認
- 次に実行すべきアクションを提案

---

### 2️⃣ 作業中に現在の状態を確認する

作業中、いつでも以下のコマンドで状況を確認できます:

```
/status
```

**表示内容**:
- 完了した作業
- 未完了のタスク（優先度別）
- 現在のブロッカー
- 推奨アクション

---

### 3️⃣ 作業完了時に状態を更新する

大きな作業を完了したら、以下のコマンドで状態ファイルを更新してください:

```
/update-status
```

**更新内容**:
- 完了したタスクの記録
- 新しく発見した問題の追加
- 次のステップの更新

または、直接Claudeに以下のように依頼することもできます:

```
SESSION_STATE.mdを更新してください。
今日完了した作業は以下です:
- XXXの修正
- YYYの実装
```

---

## 📋 利用可能なスラッシュコマンド一覧

### プロジェクト管理
- `/init` - セッション開始時に実行（作業状況の確認）
- `/status` - 現在の作業状況と次のステップを表示
- `/update-status` - SESSION_STATE.mdを更新
- `/project` - プロジェクト概要とアーキテクチャを表示

### 開発・デバッグ
- `/validate` - デプロイ前の事前検証を実行
- `/check-config` - Terragrunt設定ファイルの整合性をチェック
- `/debug` - デプロイ失敗時のトラブルシューティング
- `/explore-deps` - サービス間の依存関係を分析

---

## 💡 ベストプラクティス

### セッション開始時
1. **必ず `/init` を実行**して前回の作業を確認
2. 優先度の高いタスクから着手
3. ブロッカーがあれば先に解決

### 作業中
- 大きな作業を始める前に `/status` で確認
- 疑問があれば `/project` でアーキテクチャを再確認
- エラーが発生したら `/debug` を実行

### 作業終了時
- `/update-status` で完了した作業を記録
- 次回のための引き継ぎ事項をメモ

## 🔍 SESSION_STATE.md の構成

### 主要セクション

#### 1. 📌 現在のプロジェクト状態
- 最新の完了作業

- 各ファイルの役割

- Terragruntコマンド集
- Dockerコマンド集
- SSH接続コマンド

## 📝 カスタマイズ

SESSION_STATE.mdは通常のMarkdownファイルなので、自由に編集できます:

```bash
# エディタで開く
code .claude/SESSION_STATE.md

# または直接編集
vim .claude/SESSION_STATE.md
```

### 追加推奨セクション
- **学習メモ**: 作業中に学んだこと
- **ハマったポイント**: トラブルと解決方法
- **TODO**: 将来の拡張アイデア

## 🔐 セキュリティ注意事項

SESSION_STATE.mdはGitにコミットされます。以下の情報は**記載しないでください**:

- ❌ パスワード、トークン
- ❌ 実際のIPアドレス（サンプルのみOK）
- ❌ SSH秘密鍵
- ❌ API鍵

これらの情報は `.env` ファイルで管理し、`.gitignore` で除外されています。

## 🆘 トラブルシューティング

### SESSION_STATE.mdが見つからない
```bash
# 再作成を依頼
"SESSION_STATE.mdを作成してください"
```

### セッション状態が古い
```bash
# 最新化を依頼
"SESSION_STATE.mdを現在の状態に更新してください"
```

### スラッシュコマンドが動作しない
```bash
# コマンド一覧を確認
ls -la .claude/commands/

# コマンドファイルの内容を確認
cat .claude/commands/init.md
```
